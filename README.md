# HR Platform Frontend

Клиентская часть для приложения "HR Platform" (Веб-интерфейс)

## Стек технологий

- Vue 3 (Composition API)
- Vite (сборщик проекта)
- Vue Router 4 (маршрутизация)
- Pinia (управление состоянием)
- Axios (HTTP-клиент)
- JavaScript (ES6+)

## Запуск

### Требования

- Node.js 20+ (рекомендуется LTS-версия)
- npm (устанавливается вместе с Node.js)
- Среда разработки (рекомендуется VS Code с расширением Vue - Official или WebStorm)
- Запущенный бэкенд HR Platform (на порту 8080)
- Git

### Пошаговая инструкция

1. **Клонировать репозиторий**

   ```bash
   git clone <ссылка_на_репозиторий>
   cd hr-frontend
   ```

2. **Установить зависимости**

   Выполнить в терминале из корня проекта: `npm install`

3. **Запустить приложение**

   Убедитесь, что бэкенд запущен и база данных работает. Затем выполните: `npm run dev`

## Архитектура проекта

```
hr-frontend/
 ├── public/       # Статические файлы (favicon, robots.txt), не обрабатываются Vite
 ├── src/
 │    ├── api/          # Настройка Axios и запросы к API
 │    ├── assets/       # Ресурсы для компонентов (картинки, шрифты), обрабатываются Vite
 │    ├── router/       # Настройка маршрутов и защита от неавторизованного доступа
 │    ├── stores/       # Хранилища Pinia (auth — токены и данные пользователя)
 │    ├── views/        # Страницы приложения (LoginView, HomeView и т.д.)
 │    ├── App.vue       # Корневой компонент (содержит <router-view>)
 │    └── main.js       # Точка входа (инициализация Vue, Router, Pinia)
```
